## Strongest shortlist

For a polished public-facing tracker:
1. **LittleLoop** — captures repeating feed/sleep/diaper cycles.
2. **TinyTimeline** — immediately communicates what the app does.
3. **CareNest** — warm and broad enough to grow beyond infancy.
4. **LittleRhythm** — particularly good if sleep prediction is a flagship feature.
5. **NapCompass** — memorable, but too sleep-specific for the full product.
6. **CradleSync** — good multi-caregiver/automation feel.
7. **NurtureOS** — broad and ambitious.
8. **SateleNest** — strongest private/family-specific option.

## Naming checks before selection

Before adopting a public name:
- GitHub repository availability
- domain availability
- app-store conflicts
- trademark search
- package/container namespace availability
